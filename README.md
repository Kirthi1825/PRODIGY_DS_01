# Prodigy InfoTech — Data Science Task 1

## Data Visualization: Population Distribution

### Objective
Create visualizations to explore population data using a bar chart and a histogram.

### Dataset
The population dataset was obtained from [Our World in Data](https://ourworldindata.org/grapher/population).

The dataset contains historical population estimates. This project uses the latest available year, 2023.
### Tools and Libraries
- Python
- Pandas
- Matplotlib
- Google Colab

### Visualizations

**1. Top 10 Most Populous Countries**

A horizontal bar chart comparing the populations of the ten most populous countries in 2023.

**2. Distribution of Country Populations**

A histogram showing how country populations are distributed and helping identify differences in population size.

### Key Findings
- The bar chart allows easy comparison of population sizes across the ten most populous countries.
- The histogram helps examine the distribution of populations across countries.
- The distribution is expected to be right-skewed because a small number of countries have very large populations.

### Conclusion
This task provided practical experience in loading and inspecting data with Pandas and creating visualizations with Matplotlib.
